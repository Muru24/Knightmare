# Knightmare – 담당 기능 구현 코드

이 저장소는 **Knightmare 전체 Unity 프로젝트가 아닌, 프로젝트에서 직접 담당한 기능의 스크립트만 정리한 포트폴리오용 저장소**입니다.

원본 프로젝트의 에셋, 외부 패키지, 공용 시스템 및 다른 팀원의 작업물은 포함되어 있지 않으므로 이 저장소만으로는 게임을 실행할 수 없습니다.

## 담당 기능

- 그리드 기반 랜덤 던전 생성
- 가중치 기반 방 패턴 선택
- 일반 방 및 특수 방 배치
  - 보스방
  - 중간 보스방
  - 상점방
- 인접 방에 따른 문과 벽 자동 구성
- Render Texture 기반 미니맵
- 현재 방 및 방문한 방 상태 표시

## 사용 기술

- Unity
- C#
- 2차원 배열 기반 그리드 맵
- 절차적 생성
- 가중치 랜덤 선택
- 재귀적 방 확장
- 프리팹 동적 생성
- Singleton 패턴
- Orthographic Camera
- Render Texture
- Collider Trigger
- enum 기반 상태 관리

## 주요 스크립트

| 스크립트 | 역할 |
|---|---|
| `DungeonCrawlerController.cs` | 던전 구조 생성 및 특수 방 배치 |
| `RoomController.cs` | 방 프리팹 생성 및 관리 |
| `RoomInfo.cs` | 방의 위치, 타입, 거리 데이터 관리 |
| `RoomPrefabsSet.cs` | 방 이름과 프리팹 연결 |
| `Room.cs` | 개별 방 정보 및 상태 관리 |
| `SubRoom.cs` | 인접 방 탐색과 문·벽 구성 |
| `Door.cs` | 문의 방향과 연결된 방 관리 |
| `Wall.cs` | 벽의 방향과 생성 상태 관리 |
| `MiniMap.cs` | 미니맵 상태별 머티리얼 관리 |
| `MinimapState.cs` | 현재 방과 방문한 방 상태 처리 |
| `MinimapCam.cs` | 미니맵 카메라의 플레이어 추적 |

## 참고 사항

- 본 저장소는 담당 코드의 구조와 구현 방식을 설명하기 위한 용도입니다.
- 전체 Unity 프로젝트가 아니므로 단독 실행 및 빌드는 지원하지 않습니다.
- 프리팹, 머티리얼, 씬, 외부 에셋 등 일부 의존 리소스는 포함되어 있지 않습니다
- 상점 관련 구현 범위는 상점방의 생성·배치 및 미니맵 연동까지입니다.
